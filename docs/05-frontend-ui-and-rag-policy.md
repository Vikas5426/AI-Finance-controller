## 16. Tag-Based Policy RAG & SOP Ingestion System

Enterprise reconciliation resolutions must strictly conform to internal Standard Operating Procedures (SOPs).

### 16.1 Deterministic Tag-Based Retrieval (MVP)
For corpora under 50 documents (< 15,000 tokens), semantic vector search introduces non-deterministic retrieval risks and unnecessary infrastructure overhead. Instead, we use **deterministic tag lookup**:

```python
from typing import List
from uuid import UUID
from pydantic import BaseModel

class SOPDocument(BaseModel):
    id: str
    title: str
    tags: List[str]
    content: str
    version: str

def fetch_applicable_sops(
    exception_type: str,
    source_kinds: List[str],
    sops_db: List[SOPDocument]
) -> List[str]:
    """Retrieves SOPs matching exception type and sources with 100% precision"""
    query_tags = {exception_type}.union(set(source_kinds))
    matched_sops = []
    
    for sop in sops_db:
        if any(tag in query_tags for tag in sop.tags):
            matched_sops.append(f"[{sop.id}] {sop.title} (v{sop.version}):\n{sop.content}")
            
    return matched_sops
```

## 17. Deterministic 13-Week Forward Cash Forecasting Engine

The Cash Forecast provides treasury controllers with a mathematical forward cash projection derived from reconciled gateway receivables and observed historical settlement latencies.

### 17.1 Mathematical Formulation

$$\text{Cash}(t) = \text{Balance}(t-1) + \sum_{i \in \text{OpenReceivables}} \hat{S}(i, t) - \sum_{j \in \text{Payables}} P(j, t) - \text{Reserve}(t)$$

Where the predicted net settlement $\hat{S}(i, t)$ is computed as:

$$\hat{S}(i, t) = \text{Gross}_i \cdot (1 - \text{MDR}_{\text{pct}}) - \text{FixedFee}_i - \text{GST}_{\text{fee}}$$

Conditioned on the probability density function $P(\text{SettlementDate} = t \mid \text{CaptureDate}_i, \text{PSP}_i)$ derived from empirical historical lags.

```python
from datetime import date, timedelta
from typing import Dict, List

def compute_13_week_cash_forecast(
    opening_bank_balance_minor: int,
    reconciled_open_receivables: List[Dict[str, Any]],
    lag_distribution: Dict[int, float], # {1: 0.10, 2: 0.80, 3: 0.08, 4: 0.02}
    weeks: int = 13
) -> List[Dict[str, Any]]:
    """Calculates weekly projected cash inflows deterministically"""
    start_date = date.today()
    weekly_inflows = [0] * weeks
    running_balance = opening_bank_balance_minor

    for r in reconciled_open_receivables:
        gross = r["gross_minor"]
        net = int(gross * 0.978) # Net of 2% MDR + 18% GST on fee
        cap_date = r["occurred_at"].date()
        
        for lag_days, prob in lag_distribution.items():
            expected_date = cap_date + timedelta(days=lag_days)
            week_idx = (expected_date - start_date).days // 7
            if 0 <= week_idx < weeks:
                weekly_inflows[week_idx] += int(net * prob)

    forecast = []
    for w in range(weeks):
        week_start = start_date + timedelta(weeks=w)
        inflow = weekly_inflows[w]
        running_balance += inflow
        forecast.append({
            "week_number": w + 1,
            "week_starting": week_start.isoformat(),
            "expected_inflow_minor": inflow,
            "expected_inflow_display": inflow / 100.0,
            "closing_projected_balance_minor": running_balance,
            "closing_projected_balance_display": running_balance / 100.0
        })

    return forecast
```
